# harness/ui

Committed static snapshot of the sample hotspot map. This is what
`micro-llm-trace.exe` / `micro-llm-view.exe` host on Windows via WebView2.

Do **not** run `npm`, `npm install`, or `npm start` to open this. The files
are already built.

Source lives in `viewer/`. Maintainers refresh this tree with
`viewer/scripts/sync-harness-ui.sh`.
